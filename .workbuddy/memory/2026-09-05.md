## 2026-09-05 23:10 修复「次数用尽导致凝气成形按钮灰色、建不了角色」
**背景**：用户把 6 次「凝气成形」每日限额全点没了，现在按钮 `disabled`（前端 `quotaExhausted = remaining<=0`）。该限额是 **Redis 每日配额**（`character_generation:daily:<email|ip>:<Asia/Shanghai日期>:<sha256>`），按邮箱+IP 取更紧者、TTL 一天、次日零点重置；与账号无关、非 DB 字段。限额检查在调用生成**之前**，离线兜底也不绕过它——所以即使走本地离线生成，6 次用尽仍被 429 挡住。
**修复（让限额只在「真用 LLM」时启用）**：
- 新增 `src/shared/config/llm.ts` 的 `isLlmConfigured()`：唯一判断「LLM_PROVIDER 非空 且 ALIBABA/DEEPSEEK_API_KEY 任一非空」。
- `CharacterGenerator.generate()` 改用 `isLlmConfigured()`（去掉重复 env 判断，DRY）。
- `src/server/lib/redis/characterGenerationLimiter.ts` 新增 `isCharacterGenerationQuotaEnabled()`（= `isLlmConfigured()`）与 `getUnlimitedCharacterGenerationQuota()`（返回 `unlimited:true` 的满额占位）。
- `src/server/routes/api/generate-character.router.ts`：`GET /quota` 与 `POST /` 均改为——`isCharacterGenerationQuotaEnabled()` 为真才走 Redis 限额（429 拦截）；否则返回无限额、直接生成。
- `src/shared/contracts/character-generation.ts` 的 `CharacterGenerationQuota` 加可选 `unlimited?: boolean`。
- `src/react-app/routes/game/create/route.tsx` 的 `quotaHint`：离线时显示「当前为离线生成模式，凝气成形次数不限」。
**效果**：未配 LLM 时凝气成形**彻底不限次数**，按钮永不变灰；配了真 LLM 后每日限额自动恢复（仍有真实的外部成本保护）。tsc -b tsconfig.app.json 与 tsconfig.node.json 均通过（EXIT=0）。
**注意**：用户今日已点的 6 次 Redis 计数仍在，但离线路径根本不读/不消耗它，所以不影响。若日后当日临时启真 LLM，则会先被旧计数挡住——届时清 `character_generation:daily:*` 键或等次日即可。
