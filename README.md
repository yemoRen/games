# 全民求生・系统搜打撤

> 末世废土 · 文字放置 ·「搜—打—撤」硬核生存
>
> 当前版本：**v1.0.12** ｜ 纯前端 `localStorage` 存档，开箱即玩，无需后端

当文明崩塌，废土成为唯一的世界。一个名为「系统」的存在向每一位幸存者发布指令：**进入危险区域，搜刮物资，击退威胁，活着撤出来。**

《全民求生・系统搜打撤》是一款数据驱动的文字放置生存游戏。你经营一支幸存者战团，在废弃都市、军事禁区与核爆禁区之间反复出击，用每一次「搜打撤」积累装备、货币与声望，在死亡与撤离的张力中撑到明天。

## 核心玩法大纲

### 1. 搜打撤主循环

```
        系统发布目标
             │
             ▼
    ┌─────────────────┐
    │   据点（安全区）   │
    └────────┬────────┘
             │  出击
             ▼
    ┌───────────────────────────┐
    │      危险区域（副本）        │
    │   搜：搜刮建筑 / 容器 / 尸体  │
    │   打：遭遇战（丧尸 / 掠夺者） │
    │   撤：抵达撤离点结算          │
    └────┬───────────────┬──────┘
  撤离成功 │               │ 阵亡 / 撤离失败
         ▼               ▼
  ┌────────────┐   ┌──────────────────┐
  │ 物资入库    │   │ 未撤离物资全部遗失  │
  └─────┬──────┘   │ 出击者进入濒死状态  │
        │          └──────────────────┘
        ▼
   休整（恢复 HP / 治疗伤势）→ 强化装备 → 再出击
```

- **搜（Loot）**：进入危险区域探索建筑与容器，搜刮材料、弹药、食物与装备；越危险的区域产出越好。
- **打（Fight）**：遭遇战由真实战斗引擎结算（技能、暴击、增益、伤势全生效），敌人涵盖丧尸群、变种生物、掠夺者小队与区域首领。
- **撤（Extract）**：抵达撤离点即结算。**成功 → 本局搜刮入库；失败/阵亡 → 仅丢失本局未撤离物资**，据点资产与已装备安全。

### 1.1 成长与升级（实时同步）

经验与等级在**角色页与出击页共享同一份档案**，全程实时同步：

- **出击实时获取经验**：每次击杀/战斗后立即结算经验并写入角色档案，无需等到撤离结束；
- **途中升级即时生效**：出击过程中经验满级即升级，**状态回复全满 + 伤势清除**，并弹出**词条三选一**提示，选定后立刻生效；
- **加点 / 选词条两边通用**：能力加点（每级 +3 自由属性点）与升级词条三选一，既可在**角色页**操作，也可在**出击页**操作，两边实时同步、互不冲突；
- **词条属性计入基础六维**：升级获得的词条六维加成在选取时即并入角色基础属性，显示为白色基础值（不再以绿色「加成」重复呈现），未穿戴装备时不会凭空出现绿字。

### 1.2 出击换装规则

- 出击途中可在临时背包里就地「🎽 佩戴 / 卸下」装备；
- **带「增加气血」的装备：佩戴后只提升最大血量、脱下只降低最大血量，不影响当前血量**（满血时减最大则当前同步减少，满血加最大则当前不变，非满血时当前血量不受影响）；
- 而**加体质点**则是最大血量与当前血量**一起提升**；
- 撤离（成功）后，出击过程中换上的装备（含副本内搜到的掉落装备）会**保留并同步回角色装备栏**，后续出击沿用。

### 2. 战团与幸存者

- **主角生成**：建立档案时，以玩家代号生成一名**全属性 15、紫色（epic）品质**的主角，直接入列战团。
- **战团成员（N / 10）**：战团上限 **10 人**。副本中带回的幸存者不会自动入团。
- **幸存者花名册**：展示副本中发现的幸存者，含**属性面板 + 招募金额**（越强越贵，按下表分档）：

  | 段位 | 1 | 2 | 3 | 4 | 5 |
  | --- | --- | --- | --- | --- | --- |
  | 招募费（废土币） | 50 | 200 | 800 | 3000 | 10000 |

- **招募 / 遣散**：花废土币招募后正式入列；战团满员无法招募，需**遣散**成员（返还 **1/3** 招募价值）或等成员死亡腾位。**主角不可遣散**。

### 3. 濒死与救治

撤离失败 / 阵亡的成员返回战团会进入**濒死**状态：

- 血量骤降至约 **5%**，并附带流血 / 骨折 / 惊惧等伤势，期间不可再次出击；
- 开启 **10 分钟救治倒计时**；
- 可用 **100 废土币**或任意**医疗品**救治（恢复约 50% 血量并清除伤势）；
- 若**长时间未救治**，成员死亡并自动离开战团。

### 4. 装备与制造

- 战利品含带**阶级词缀**的装备（白 → 绿 → 蓝 → 紫 → 黄 → 橙 → 红），阶级越高属性越强、出现越稀有；
- 制造 / 改装台消耗材料与废土币产出带词缀的武器、护甲、义体、配件；
- 装备的战斗词条（气血上限 / 暴击 / 搜刮运势）真实带入出击。

### 5. 避难所与据点

- 避难所设施（瞭望塔 / 医疗站 / 改装工坊 / 训练场）可升级，提供驻防被动；
- 战团声望投资解锁长期加成；
- 据点温室 / 生产车间提供稳定产出。

### 6. 末世行止（菜单系统）

仿系统终端的菜单，涵盖：医疗中心、废土市场、探险札记、任务中心、英雄榜、世界传闻、兑换码、意见反馈、系统设置等模块。

## 技术概览

- 服务端：`Hono` + `Bun`
- 前端：`React 19` + `React Router 7` + `Vite`
- 样式：`Tailwind CSS 4`
- 战斗引擎：时间轴回合制战斗（技能 / 词条 / Buff 全配置驱动）
- 持久化：浏览器 `localStorage` 存档（按账号隔离），无需服务端数据库即可游玩
- AI 旁白：可接入 LLM 做「末世生存系统」实时播报

## 本地运行

环境要求：安装 [Bun](https://bun.sh)（≥ 1.x）。

```bash
bun install        # 安装依赖
bun run dev        # 启动开发服务器（前端 + API 并行）
# 浏览器打开 http://localhost:5173/ ，进入 /survival 注册即可游玩
```

其他命令：

```bash
bun run build      # 生产构建
bun run lint       # ESLint
bun run check      # 类型检查
bun run test       # 运行 src/shared 下的纯引擎单测
```

### v1.0.11（2026-09-09）— 濒死与等级门槛治理 + UI 紧凑化 + 副本内容贴合

本版累计三轮改动，核心目标：① 把「难度」交还给等级与装备成长（低等级禁入高危区、濒死禁出击 / 禁遣散）；② 出击内 UI 进一步紧凑、与末日废土叙事统一；③ 各大副本 16 区名贴合主题。

**第一轮（3 项）**

- **濒死角色禁止再次出击**：副本结算横幅「再次出击」按钮 `disabled={activeDying}`（濒死 = `survivorStatus.dyingUntil` 未过期），`start()` 顶部加濒死守卫；出击前选择页「出击 ▶」按钮同步 `disabled={selLocked || activeDying}`。根因：之前濒死角色点再次出击会带伤复活在副本入口。
- **副本等级门槛**：新增 `DANGER_LEVEL_REQ`（危1→不限 / 危2→Lv3 / 危3→Lv5 / 危4→Lv8 / 危5→Lv10 / 危6→Lv12 / 危7→Lv15）。选择页每个副本按钮按 `active.level` 判定 `disabled` 并显示「需 Lv.N」徽标；`start()` 与「出击 ▶」双保险拦截。1 级角色彻底进不了危7。
- **副本难度提升（靠等级门槛，而非盲目放大敌人数值）**：实测战斗引擎存在「数值悬崖」——敌人基础六维仅放大 ~5% 即让通关胜率从惨胜跌到 0%（疑似跨过秒杀阈值）。故难度主要由「等级门槛 + 区域危险度（装备爆率）+ 深度词缀（遇怪）」三层间接控制；另埋 `ENEMY_DANGER_SCALE` 钩子（content.ts / ExtractionEngine.fight 套用），当前全 1.0（no-op），留作日后充分实测后再调。

  - 背包装备库列表改为按 **阶位（tier）从高到低降序** 显示，高阶装备置顶；
  - 修复批量卖出勾选异常：点击单件装备卡顿时无法取消、勾选会连带选中属性完全相同的其他装备、以及偶发复制/假显示的问题（根因为列表使用数组下标 `index` 作为 React key，导致勾选态错位；改为以装备稳定 `uid` 作为 key 与选中依据）。
- **撤离结算折算（修复）**
  - 修正「撤离后金额暴涨」：`bankLoot` 此前会把战利品估值（`value×qty`）一并累加进基地废土币金额，导致除废土币外的材料估值也变成钱。

- **金币获取加成直抵废土币（优化）**
  - 拾荒嗅觉 / 装备「金币获取 +n%」词条现在**直接体现在搜刮到的废土币数量**上：无加成角色每轮搜得 25 废土币，金币加成 100% 的角色则搜得 50 废土币；

### v1.0.3（2026-09-07）

体验打磨与一批修复（相对 v1.0.2）：
